각 문서는 독립적으로 읽을 수 있습니다. 관심 있는 주제부터 시작해도 됩니다.

## 이 저장소가 다루지 않는 것

**Formology에는 구현체가 없습니다.**

기술 스택 추천, 프로젝트 스캐폴딩, 코드 템플릿, 성능 튜닝, 배포 구성 — 전부 범위 밖입니다. [도출 원리](derivation.md)에 SQL 예시가 있지만 그것은 **규칙이 작동함을 보이는 예시**이지 권장 구현이 아닙니다.

방법론이 답하는 것은 하나입니다: **서식에서 무엇이 어떻게 도출되는가.** 그것을 무엇으로 만들지는 구현체의 몫입니다.
