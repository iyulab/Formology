## 문서 구조

```
왜?        → philosophy.md    철학, 원칙, 시대적 비판
무엇?      → methodology.md   문서 분류, 흐름, 구조, 관계, 데이터 모델링
어떻게?    → workshop.md      준비, 진행, 산출물 (실전 가이드)
어떻게 만드나? → realization.md   DB, API, UI, 사례, 참고
```

| 문서 | 질문 | 핵심 내용 | 추천 독자 |
|------|------|----------|-----------|
| **[철학과 원칙](philosophy.md)** | 왜? | 눈손이와 문서주의의 대가, 회원등록카드, Entity-CRUD 비판, AI 시대 두 번째 물결, 10대 원칙, 8대 명제, 온톨로지 관계와 도출 불가 영역, 반증 조건 | 전체 |
| **[방법론](methodology.md)** | 무엇? | 서/지/표/록 분류, 흐름 7패턴과 선행 조건, FormType→Form→Document→Record, 참조/붙임/스냅샷, 네이밍, Section→Entity 사상 | 분석가, 설계자 |
| **[워크숍 가이드](workshop.md)** | 어떻게? | 성립 조건, 참석자 구성, 퍼실리테이션, 산출물 관리, 디지털화 타임라인 | 진행자, PM |
